Mock OctoPrint control

Sliders and layer boxes switch the mock to manual mode and hold the values. Dependent values (print time, time left, ETA, M73, file position) follow the progress percent. Typing a layer sets the percent from current divided by total; moving the progress slider sets the current layer from the percent.
