OctoPrint
3D Printer page

Adds a page that shows what your 3D printer is doing: print progress, time remaining, hotend and bed temperatures, and layer info. The data comes from OctoPrint, so the device needs the address of your OctoPrint server and an API key from it.

Create the key in OctoPrint under Settings, Application Keys, or use the global API key under Settings, API. Paste it into the API Key field below.

Page Layout changes how the printer page looks on the device. The Image setting picks what is shown alongside the numbers: the model preview embedded in the sliced file, or a live picture from the printer camera.

Enable 3D Printer page
Adds the printer page and starts reading from OctoPrint. Off hides the page and stops the requests.
Connection
Address of your OctoPrint server, the same one you open in a browser. Include http:// or https:// and a port number if you use one.
Create one in OctoPrint under Settings, Application Keys. Without it OctoPrint refuses the requests and the page stays empty. A key you have already saved is not shown again: leave the field untouched to keep it, or type a new key to replace it.
Asks OctoPrint to issue a key for this display, so you do not have to create and copy one yourself. Fill in the OctoPrint Address above and press Save first, then approve the request when OctoPrint asks. The key is saved for you as soon as you approve.
How often the device asks OctoPrint for new job and temperature values, in seconds (2 to 300).
Appearance
Changes the look of the printer page on the device. Bento grid arranges the numbers in cards; Immersive image fills the screen with the picture and lays the readings over it. The same values are shown either way.
G-code preview shows the model picture saved inside the sliced file, which needs the PrusaSlicer Thumbnails plugin installed in OctoPrint. Camera snapshot shows a still picture from the OctoPrint webcam.
Leave blank to use the standard OctoPrint webcam address. Fill this in only if your camera is somewhere else, and enter the full address starting with http:// or https://.
