OctoPrint
OctoPrint page

Adds a page that shows what your 3D printer is doing: print progress, time remaining, hotend and bed temperatures, and layer info. The data comes from OctoPrint, so the device needs the address of your OctoPrint server and an API key from it.

Connection holds the address and key, Appearance picks how the page looks, and Picture picks what is shown alongside the numbers.

Enable OctoPrint page
Adds the OctoPrint page and starts reading from OctoPrint; off hides the page and stops the requests.
Connection
Connection

OctoPrint Address is the address of your OctoPrint server, the same one you open in a browser. Include http:// or https:// and a port number if you use one.

Authenticate opens OctoPrint in a new tab. Sign in if asked and press Allow. The key is stored on this display as soon as you approve, and the address above is saved when you press Authenticate.

If that does not work for your OctoPrint, create a key yourself under Settings, Application Keys, and paste it into the manual field. Leave the manual field untouched to keep a saved key.

Update Interval sets how often the device asks OctoPrint for new job and temperature values, from 2 to 300 seconds.

Appearance
Appearance

Page Layout changes the look of the OctoPrint page on the device. Grid arranges the numbers in cards. Immersive image fills the screen with the picture and lays the readings over it. Floating overlay fills the screen with the picture and floats the readings directly on it, with no panels. Letterbox shows the picture between a solid top bar and a solid bottom bar, with no text over the picture. The same values are shown either way. Floating overlay and Letterbox are square panels only and are not listed on a round panel.

Show readings over picture off hides the status, temperatures and progress readings so only the picture shows. Tapping the OctoPrint page on the device shows or hides them temporarily; this setting is what it returns to. Not used by the Grid layout.

Picture
Picture

Image picks what is shown alongside the numbers. G-code preview shows the model picture saved inside the sliced file, which needs the PrusaSlicer Thumbnails plugin installed in OctoPrint. Camera snapshot shows a still picture from the OctoPrint webcam.

Camera Snapshot Address can be left blank to use the standard OctoPrint webcam address. Fill it in only if your camera is somewhere else, and enter the full address starting with http:// or https://.
